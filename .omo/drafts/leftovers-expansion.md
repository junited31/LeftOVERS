## Decisions (with rationale)
- Preserve the current recipe topology and exactly-three/deterministic-ranking contracts; add no recipe DB/corpus/crawler.
- All overlapping Android UI/resource/test edits use one writer in this order: locales -> onboarding/Settings -> pantry suggestions/fractions -> RecipeKind/history -> final-photo visibility. Backend and publication-contract writers may run in parallel when their file scopes do not overlap.
- English is the application default regardless of device locale; only English and Korean are offered. Translate display resources only, never IDs, UUIDs, enums, canonical units, or wire values.
- The 17 lowercase pantry canonical IDs are matched for display by exact case-sensitive string equality only: no trim, case-fold, Unicode normalization, or locale-sensitive comparison. Any saved exact ID, including manually typed `onion`, localizes; `Onion`, `Onion `, `onion `, and every other non-exact custom string remain verbatim. Add no provenance flag or schema field.
- Request `locale` is exactly `en|ko`, is required only on the recipe-generation request, and drives generated human-language content; the response does not echo locale. `RecipeKind` is exactly `meal|drink|snack|dessert`, is required on request and every response candidate, and missing/unknown/mismatched candidate kind fails closed before ranking or persistence.
- `RecipeSteps.recipeKind` is required with no default. Only the two explicit legacy local array/object JSON decoder branches synthesize Meal for a missing key; all constructors, new local JSON, and network decoding must supply a kind. Do not add a Room column or schema migration.
- Before final-photo ownership entry, cancellation has no effects. Once entered, a committed log must keep an existing referenced file; transaction failure attempts compensation deletion, and an orphan is tolerated only when that deletion itself fails or the process dies. Minimal startup/retry reconciliation obtains Room-referenced paths first and deletes only unreferenced files inside the exact managed retained directory; it never deletes referenced paths, unknown files, or paths outside that directory.
- Recipe models are fixed: recipe primary `gemini-3.1-flash-lite`, fallback `gemini-3.5-flash`; advice primary `gemini-3.5-flash`, fallback `gemini-3.1-flash-lite`.
- Transient fallback allowlist is only timeout, connection error, and provider 429/500/503. App auth/quota/request validation, provider auth/permission/config/model-not-found, schema/domain failure, and safety refusal never cause model fallback. Safety metadata is classified before JSON parsing.
- Disable SDK retry. Every logical HTTP request creates one immutable budget value after validation/quota admission and passes updated copies explicitly through every `parse_model_output`, adapter-method, and provider-attempt boundary; the cached adapter/client, globals, closures, context/thread locals, and request body hold no mutable budget. It spans the initial+two repair attempts: no more than three ordinary primary schema-attempt invocations, two extra primary invocations caused by allowed transients after 250/500 ms, and one fallback invocation total. Fallback is selected only after transient budget exhaustion, never retried, and remains consumed if its response is schema/domain-invalid; any still-available repair attempt returns to primary. Simultaneous identical requests have independent object lineages, delays, and caps. Quota is consumed once before this budget.
- Production uses Vertex ADC with location `global`; Cloud Run stays `asia-northeast3`. Android/repository receive no Vertex key.
- Keep OpenAI code, pinned package, and deployed secret through parity and cutover; no runtime OpenAI-Vertex fallback and no deletion without explicit future approval.
- Local gates and injected-fake proof must be green before an explicit human authority todo.
