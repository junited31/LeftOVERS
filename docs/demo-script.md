# Narrated demo script

Target: 165 seconds. Hard stop: 179 seconds. Record a physical Android device in portrait orientation, keep audio narration audible throughout, and avoid showing terminal tokens, cloud credentials, notification contents, or unrelated personal data.

| Time | Device action | Narration |
|---|---|---|
| 0-12s | Open LeftOVERS on the seeded pantry. | "LeftOVERS helps me cook from food I already have, while keeping my pantry and meal history on this device." |
| 12-28s | Show rice, spinach, eggs, quantities, and expiry dates. Open equipment. | "I track quantities and expiry dates and select only the equipment available in this kitchen." |
| 28-55s | Request recipes and show all three cards. | "GPT-5.6 returns exactly three structured, equipment-compatible choices. The app validates pantry bindings and diversity, then ranks coverage, expiry urgency, preference, and novelty." |
| 55-75s | Open one recipe and start cooking. Advance one step. | "The selected recipe becomes a local snapshot, so an active cooking session remains usable offline." |
| 75-105s | Select the prepared 256-by-256 synthetic cooking fixture and show advice. | "Only when I choose a cooking-step photo is it sent for transient analysis. The response is structured and reminds me that a photo cannot prove doneness or food safety." |
| 105-130s | Complete the recipe, confirm ingredient use, add rating and feedback. | "Completion deducts confirmed ingredient use atomically and saves my rating, adjustments, and recommendation preference locally." |
| 130-148s | Enable airplane mode, reopen History, and open the completed meal. | "The pantry, recipe snapshot, feedback, and completed history remain available offline." |
| 148-165s | Return to the home screen and show the project URL as an overlay. | "The OpenAI key stays on the backend, every model request uses store=false, and fixed global quotas are the actual cost boundary. The code and demo APK are linked with this submission." |

## Recording checklist

- Start from the ADB-seeded debug APK and a clean notification shade.
- Use the synthetic solid-color cooking fixture generated by the instrumentation flow; do not show a personal photo.
- Show three distinct recipe choices before selecting one.
- Show the safety note with photo advice.
- Demonstrate offline history after completion.
- Record continuous, intelligible narration; do not replace it with silent captions.
- Export below 180 seconds, watch the exported file end to end, then upload as Public rather than Unlisted.
- Run `ffprobe` against the exact exported file. Record its observed duration, audio stream count, and SHA-256 in `dist/leftovers-demo-media.json`; do not infer those values from the editor timeline.
- Verify the public YouTube URL in a signed-out browser before recording it in `docs/submission.md`.

The evidence JSON must use this strict shape: `schema_version` 1, lowercase `media_sha256`, numeric `duration_seconds` below 180, positive integer `audio_stream_count`, and `probe_tool` equal to `ffprobe`. The verifier binds it to `dist/leftovers-demo.mp4`. The demo file, evidence, and public URL are pending; this script is not proof that any of them exist.
